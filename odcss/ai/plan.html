Tài liệu kỹ thuật đặc tả kiến trúc, cơ sở dữ liệu và mã nguồn thực thi chi tiết cho các tính năng AI trong Qaly Project.

1. Bối cảnh

Tổng Quan & Hiện Trạng Hệ Thống

Module Nhóm (WorkGroup) trong Qaly hiện tại tích hợp luồng trò chuyện trực tiếp qua SignalR và họp trực tuyến qua LiveKit. Đồng thời, hệ thống đã trang bị một số API tĩnh cho AI tại GroupAiController.cs thông qua service GroupAiService.cs.

Các Tính Năng AI Hiện Có & Điểm Cần Cải Tiến:

Tính năng Mô tả hoạt động Hạn chế / Điểm nghẽn cần xử lý
Tóm tắt thảo luận (Discussion Summary) Chỉ quét tin nhắn tĩnh (mặc định 80 tin nhắn gần nhất) qua API endpoint POST /api/groups/{groupId}/ai/summary để trích xuất JSON tóm tắt. Thiếu tính tương tác. Người dùng phải click nút thủ công để generate và không thể hỏi sâu thêm về các chi tiết cụ thể trong cuộc thảo luận.
Dự thảo dự án (Draft Project) Dự thảo cấu trúc dự án và danh sách công việc tương ứng dựa trên đoạn chat tĩnh. Tự động gán người phụ trách (assignee) chỉ dựa trên so khớp chuỗi văn bản thô (Họ tên), chưa kiểm tra năng lực và khối lượng task thực tế của thành viên.
Ghi nhận hành động (Action Items) Trích xuất các việc cần làm từ đoạn chat tĩnh. Không tự động chạy ngầm, không thể cảnh báo realtime khi một thành viên đưa ra cam kết trong chat.
2. Kế hoạch đề xuất

Đặc Tả Chi Tiết 5 Ý Tưởng AI Mới

Các ý tưởng này được thiết kế để hoạt động liên mạch, tối ưu hóa các điểm nghẽn hiện tại và tạo ra trải nghiệm "Wow" thực thụ cho người dùng.

Ý tưởng 1: AI Group Copilot (Trợ lý Nhóm Realtime qua Chat)

Thành viên tag trực tiếp @AI vào khung chat nhóm. Hệ thống sẽ nhận dạng qua SignalR Hub, gọi dịch vụ AI xử lý và broadcast câu trả lời lại luồng chat realtime.

💡 Giải pháp kỹ thuật
Sử dụng SignalR Hub để chặn các tin nhắn bắt đầu bằng @AI. Trích xuất text phía sau làm prompt. Tải context bao gồm: thông tin dự án hiện tại, 50 tin nhắn gần nhất và các tài liệu đính kèm liên quan để thực hiện RAG (Retrieval-Augmented Generation).
🎯 Cách dùng (Use case)
User gõ: @AI tóm tắt các file yêu cầu nghiệp vụ vừa gửi lên và cho biết deadline dự án là bao nhiêu?. AI trả lời trực tiếp dưới dạng bảng Markdown trong chat sau vài giây kèm hiệu ứng "Qaly AI đang gõ...".
Ý tưởng 2: Realtime Meeting Assistant (Trợ lý cuộc họp LiveKit)

Khi cuộc họp LiveKit trực tuyến diễn ra, hệ thống tự động ghi âm, chuyển thể giọng nói thành văn bản thời gian thực (Speech-to-Text) và hiển thị danh sách "AI Smart Tasks" đề xuất tạo công việc ngay lập tức.

💡 Giải pháp kỹ thuật
Tích hợp API ghi âm giọng nói Web Audio API trên client hoặc capture audio track từ LiveKit. Gửi audio chunks qua WebSocket/SignalR lên server. Server sử dụng Whisper API/Google STT để dịch thành text và broadcast lại client. Cuối cuộc họp gọi LLM trích xuất Action Items.
🎯 Cách dùng (Use case)
Trong màn hình cuộc gọi, bật tab "AI Assistant". Khi sếp nói: *"Huy chịu trách nhiệm viết tài liệu thiết kế database trước thứ Tư tuần sau"*, AI tự động render một task nháp trên màn hình với Assignee là Huy và Due Date tương ứng.
Ý tưởng 3: AI Smart Poll Generator (Tự động hóa Khảo sát)

Tự động phân tích các cuộc thảo luận bất đồng ý kiến hoặc mang tính chọn lựa giữa các phương án trong chat nhóm để đề xuất tạo nhanh một cuộc khảo sát tối ưu.

💡 Giải pháp kỹ thuật
Sử dụng Sentiment & Topic Classification trên nền tin nhắn chat. Nếu phát hiện các câu hỏi so sánh hoặc tranh luận, AI gọi LLM tổng hợp các lựa chọn, viết 1 câu tóm tắt ưu/nhược của mỗi lựa chọn để đưa vào dữ liệu Poll.
🎯 Cách dùng (Use case)
Thành viên tranh luận: *"Nên dùng React hay Vue cho frontend mới nhỉ?"*. AI hiển thị banner nhỏ: *"Phát hiện nhóm đang biểu quyết công nghệ UI. Click để tạo Poll Khảo sát"*. Bấm click sẽ render Poll gồm 2 lựa chọn Vue & React kèm bảng so sánh.
Ý tưởng 4: AI Team Sentiment & Burnout Monitor (Chỉ số Sức khỏe Nhóm)

Đo lường gián tiếp mức độ stress, áp lực và không khí làm việc của nhóm dựa trên giọng điệu hội thoại chat và tiến độ công việc để đưa ra cảnh báo sớm cho quản lý.

💡 Giải pháp kỹ thuật
Định kỳ quét các hội thoại chat theo ngày (ẩn danh hóa tên người dùng để bảo mật). Sử dụng LLM phân tích Sentiment Score (Positive, Negative, Stressed). Kết hợp với tỷ lệ trễ hạn Task và số giờ làm việc ban đêm để tính toán Burnout Index.
🎯 Cách dùng (Use case)
Quản lý truy cập tab "Thống kê Nhóm". AI đưa ra cảnh báo: *"Chỉ số áp lực nhóm tăng 35% trong tuần qua. Đề xuất: Phân chia bớt công việc cho các thành viên khác hoặc dời lịch bàn giao dự án."*
Ý tưởng 5: AI Smart Workload Balancing (Phân bổ Công việc Thông minh)

Khi lập dự thảo dự án từ đoạn chat, AI sẽ không gán bừa bãi mà phân tích năng lực thực tế và khối lượng công việc hiện tại của từng người để đưa ra gợi ý người phụ trách tối ưu nhất.

💡 Giải pháp kỹ thuật
Xây dựng bảng kỹ năng thành viên và liên kết với dữ liệu Task đang hoạt động. Khi gọi API Draft Project, cung cấp danh sách thành viên kèm trạng thái bận/rảnh và kỹ năng chính cho LLM. LLM sử dụng thuật toán tối ưu hóa phân vai.
🎯 Cách dùng (Use case)
Khi xem bảng dự thảo công việc trong GroupAiPanel.vue, các tasks tự động điền sẵn tên Assignee kèm theo nhãn giải thích: *"Gợi ý: Huy (Có kinh nghiệm làm Vue 3 và hiện đang chỉ phụ trách 1 task active)"*.

5. Triển khai code

Mã Nguồn Triển Khai Hoàn Chỉnh

Mã nguồn đặc tả chi tiết cho phần tương tác @AI realtime bằng SignalR (Backend C#) và hiển thị UI (Vue 3 Client).

Qaly.Web/Hubs/GroupHub.cs (Snippet mở rộng)
using Microsoft.AspNetCore.SignalR;
using Qaly.Application.Services;
using Qaly.Application.DTOs.Ai;

namespace Qaly.Web.Hubs;

public partial class GroupHub : Hub
{
    private readonly IGroupAiService _groupAiService;
    private readonly ILogger<GroupHub> _logger;

    public GroupHub(IGroupAiService groupAiService, ILogger<GroupHub> logger)
    {
        _groupAiService = groupAiService;
        _logger = logger;
    }

    public async Task SendMessageToGroup(Guid groupId, string content)
    {
        // 1. Gửi tin nhắn của User tới nhóm
        var senderId = Context.UserIdentifier;
        await Clients.Group(groupId.ToString()).SendAsync("ReceiveMessage", senderId, content, DateTimeOffset.UtcNow);

        // 2. Kiểm tra trigger @AI
        if (content.Trim().StartsWith("@AI", StringComparison.OrdinalIgnoreCase))
        {
            // Fire-and-forget: Chạy background job để không block WebSocket chính
            _ = Task.Run(async () => 
            {
                try 
                {
                    // Broadcast trạng thái AI đang gõ
                    await Clients.Group(groupId.ToString()).SendAsync("SetAiTypingStatus", true);

                    var prompt = content.Substring(3).Trim(); // Cắt chuỗi bỏ chữ "@AI"
                    var result = await _groupAiService.ExecuteInteractiveQueryAsync(groupId, Guid.Parse(senderId), prompt);

                    // Broadcast câu trả lời của AI cho cả nhóm
                    await Clients.Group(groupId.ToString()).SendAsync("ReceiveMessage", "AI_BOT", result.Data, DateTimeOffset.UtcNow);
                }
                catch (Exception ex)
                {
                    _logger.LogError(ex, "Lỗi tương tác AI tại Group {GroupId}", groupId);
                    await Clients.Group(groupId.ToString()).SendAsync("ReceiveMessage", "AI_BOT", "Đã xảy ra sự cố khi gọi AI. Vui lòng thử lại sau.", DateTimeOffset.UtcNow);
                }
                finally 
                {
                    // Tắt trạng thái AI đang gõ
                    await Clients.Group(groupId.ToString()).SendAsync("SetAiTypingStatus", false);
                }
            });
        }
    }
}
GroupAiService.cs (Các API mở rộng mới)
// Thêm các hàm xử lý mới vào GroupAiService hiện có
public async Task<Result<string>> ExecuteInteractiveQueryAsync(Guid groupId, Guid userId, string prompt, CancellationToken ct = default)
{
    // 1. Tải context 30 tin nhắn gần nhất để tạo tính hội thoại
    var chatContext = await BuildGroupChatContextAsync(groupId, 30, ct);
    var contextText = chatContext.Data ?? "";

    // 2. Chuẩn bị prompt với system context
    var systemPrompt = $$"""
    Bạn là Trợ lý AI Qaly Copilot của nhóm. Bạn đang tham gia luồng chat nhóm trực tiếp.
    Dưới đây là lịch sử hội thoại gần nhất của nhóm:
    {{contextText}}

    Hãy trả lời trực tiếp câu hỏi sau một cách ngắn gọn, súc tích (dưới 300 từ). Sử dụng Markdown nếu cần thiết.
    Yêu cầu của người dùng: {{prompt}}
    """;

    // 3. Gọi AI Gateway xử lý
    var response = await _aiGateway.ExecuteAsync(new AiRequest
    {
        JobType = "InteractiveChat",
        Prompt = systemPrompt,
        UserId = userId.ToString(),
        UseCache = false
    }, ct);

    // 4. Lưu lại lịch sử vào database mới
    var chatLog = new GroupAiChatHistory
    {
        WorkGroupId = groupId,
        SenderUserId = userId,
        PromptText = prompt,
        ResponseText = response.Content
    };
    await _unitOfWork.Repository<GroupAiChatHistory>().AddAsync(chatLog, ct);
    await _unitOfWork.SaveChangesAsync(ct);

    return Result.Success(response.Content);
}
Qaly.Web/ClientApp/components/chat/ChatWindow.vue (Giao diện tích hợp AI)
<script setup lang="ts">
import { ref, onMounted, nextTick } from 'vue';
import { Sparkles, Send } from 'lucide-vue-next';

const props = defineProps<{ groupId: string }>();

const messages = ref<any[]>([]);
const inputText = ref("");
const isAiTyping = ref(false);
const chatContainer = ref<HTMLElement | null>(null);

// Giả lập kết nối SignalR Hub đã cấu hình ở TeamsPage.vue
const sendMessage = async () => {
  if (!inputText.value.trim()) return;
  
  const content = inputText.value;
  inputText.value = "";
  
  // Gửi tin nhắn qua SignalR Hub
  await signalrConnection.invoke("SendMessageToGroup", props.groupId, content);
};

onMounted(() => {
  signalrConnection.on("ReceiveMessage", (senderId: string, text: string, time: string) => {
    messages.value.push({ senderId, text, time });
    scrollToBottom();
  });

  signalrConnection.on("SetAiTypingStatus", (status: boolean) => {
    isAiTyping.value = status;
    scrollToBottom();
  });
});

const scrollToBottom = () => {
  nextTick(() => {
    if (chatContainer.value) {
      chatContainer.value.scrollTop = chatContainer.value.scrollHeight;
    }
  });
};
</script>

<template>
  <div class="chat-window">

          <div class="typing-dots">
            <span></span><span></span><span></span>
          </div>
        </div>
      </div>

    <!-- Khung nhập tin nhắn chat -->

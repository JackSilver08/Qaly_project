#2. Quy Tắc Giải Quyết Mâu Thuẫn Phân Quyền & Real-Time Invalidate

⚖️ Conflict Resolution Precedence (Thứ Tự Ưu Tiên Quy Tắc):
Level 1 (Highest): Explicit Deny
Nếu System Role hoặc System User Override cấu hình Deny module X -> Deny tuyệt đối, bất kể Project Role có cho phép hay không.
Level 2: Project Granular Override
Nếu System Level cho phép -> Cấu hình của Project Custom Role hoặc Project Member Matrix sẽ quyết định quyền chi tiết (Kanban Edit, Roadmap View Only...).
Level 3: Default Role Fallback
Sử dụng quyền mặc định của System Role (Admin / User).
⚡ SignalR Real-Time Invalidation:

Khắc phục lỗ hổng Pinia Cache bị thiu: Ngay khi Admin sửa ma trận phân quyền, SignalR Hub phát sự kiện "PermissionUpdatedEvent" tới Channel của User/Project tương ứng. Client tự động âm thầm refetch permission matrix mà không bắt user phải ấn F5 reload trang!

await _hubContext.Clients.User(targetUserId)

6 Trụ Cột Năng Lực AI Trong Quản Trị Lộ Trình (Erumi AI 2.0)

Các tính năng AI chuyên sâu được tối ưu hoá riêng cho Quản lý Lộ trình (Roadmap / Milestones / Sprints)

LLM Engine: Gemini 1.5 Pro / GPT-4o

1. Smart Scope & WBS Generator

Tự động sinh Lộ trình đa tầng từ Mục tiêu

Chỉ cần nhập mục tiêu lớn (ví dụ: "Xây dựng tính năng thanh toán VNPay & Mobile App"), AI tự động bóc tách thành các Phase & Milestone hợp lý theo chuẩn Agile, kèm thời lượng dự kiến, độ ưu tiên và phụ thuộc (Dependencies DAG).

⚡ Input: 1 dòng Goal / Spec Document
🎯 Output: WBS 3 cấp (Phase ➔ Milestone ➔ Tasks)

2. Project Expander & Phase Scaler

Mở rộng dự án không gãy kiến trúc cũ

Khi khách hàng yêu cầu mở rộng quy mô (Scale up, thêm Security Hardening, Audit Compliance, chuyển đổi Microservices), AI phân tích lộ trình hiện có và gợi ý chèn Phase mới hoặc kéo dài Phase mà không làm xáo trộn các mốc bàn giao đã chốt.

🛡️ Giữ nguyên Phase Completed
🔄 Tự động dời mốc các Phase chưa khởi chạy

3. Bottleneck & Critical Path Radar

Phát hiện điểm nghẽn & rủi ro trễ hạn

Thuật toán AI liên tục quét tiến độ thực tế so với Deadline dự kiến. Tự động đánh dấu Đường găng (Critical Path) có nguy cơ trễ hạn, chỉ rõ task nào đang chặn (blockers) các task tiếp theo và đưa ra gợi ý xử lý tức thì.

⚠️ Cảnh báo xung đột Dependencies
📈 Xác suất hoàn thành đúng hạn (Confidence %)

4. Workload Auto-Balancer & Smart Assign

Cân bằng tải & gán việc theo Năng lực

Phân tích năng lực thực tế của từng thành viên (Backend, Frontend, QA, DevOps). Ngăn chặn tình trạng quá tải (>40h/tuần), tự động đề xuất gán task mới cho người phù hợp nhất dựa trên lịch sử hoàn thành công việc và kỹ năng chuyên môn.

👥 Capacity Matrix per Member
🚫 Tự động gắn cờ cảnh báo Burnout / Overload

5. What-If Scenario Simulation

Mô phỏng kịch bản giả định trong Sandbox

Cho phép Owner/PM đặt câu hỏi giả định: "Nếu rút ngắn Phase 2 xuống 1 tuần thì cần thêm bao nhiêu nhân sự?" hoặc "Nếu khách thêm tính năng Chat Realtime thì dự án trễ bao lâu?". AI chạy mô phỏng không làm ảnh hưởng dữ liệu thật.

🧪 Sandbox Sandbox Mode độc lập
📊 So sánh 3 kịch bản: Optimistic / Realistic / Pessimistic

6. Executive Client Presentation AI

Tự động tổng hợp Báo cáo cho Sếp & Đối tác

1-Click biến dữ liệu Roadmap kỹ thuật phức tạp thành bản trình bày Executive Client View tinh gọn, chuyên nghiệp, ẩn các task nội bộ nhạy cảm và nêu bật các cột mốc bàn giao (Milestone Deliverables) cùng giá trị kinh doanh.

📄 Xuất PDF / Web View chia sẻ an toàn
🗣️ Tóm tắt giọng văn chuyên nghiệp (Executive Brief)

Cơ Chế Bảo Vệ 3 Lớp Phía Backend .NET (Multi-Layer Security Guard)

1. System Level (AiHub)

Kiểm tra tài khoản có bị System Admin khóa module AI hay không thông qua bảng SystemModulePermission.

2. Project Level (Owner/PM)

Kiểm tra UserId có khớp với Project.OwnerId hoặc role có quyền Roadmap.ApproveAiDiff.

3. Audit Logging (Ghi vết)

Ghi lại mọi hành động Duyệt hoặc Rollback vào AuditLogService phục vụ truy vết bảo mật.

1. C# DTO Models (Qaly.Application.DTOs.Ai)

ErumiRoadmapDtos.cs 
namespace Qaly.Application.DTOs.Ai;

// Fast Action Trigger DTO
public record ErumiRoadmapActionRequestDto(
    Guid ProjectId,
    string ActionType, // "ExpandPhase" | "AuditRisks" | "AutoBalance" | "BreakdownWBS" | "Forecast"
    string? UserPrompt,
    Guid? TargetSprintOrPhaseId,
    string? ContextSprintName);

// Proposal Diff Snapshot DTO
public record ErumiRoadmapDiffProposalDto(
    Guid SnapshotId,
    Guid ProjectId,
    string PhaseName,
    DateTimeOffset EstimatedStartDate,
    DateTimeOffset EstimatedEndDate,
    IReadOnlyList<ErumiTaskProposalDto> ProposedTasks,
    IReadOnlyList<ErumiWorkloadImpactDto> WorkloadImpacts,
    string Summary,
    double ConfidenceScore);

// Task Proposal Item
public record ErumiTaskProposalDto(
    string Title,
    string Description,
    string Priority,
    int EstimatedHours,
    string RecommendedRole,
    Guid? RecommendedAssigneeId,
    string? RecommendedAssigneeName);

// Workload Impact Radar DTO
public record ErumiWorkloadImpactDto(
    Guid MemberUserId,
    string MemberName,
    string CurrentRole,
    int CurrentWeeklyHours,
    int ProposedAdditionalHours,
    bool IsOverloaded,
    string WarningMessage);

// Approval Request DTO (Chỉ Owner/PM gọi)
public record ApproveErumiRoadmapProposalDto(
    Guid SnapshotId,
    Guid ProjectId,
    List<ErumiTaskProposalDto> ApprovedTasks);

// Rollback Snapshot DTO (Undo 1-chạm)
public record RollbackErumiRoadmapSnapshotDto(
    Guid SnapshotId,
    Guid ProjectId);

2. Danh Sách REST API Endpoints Phục Vụ Module

Method Endpoint URL Quyền Tối Thiểu Mục Đích Sử Dụng
POST /api/erumi-roadmap/fast-action Project Member Kích hoạt Fast Action AI (Mở rộng, Phân tích rủi ro, Sinh WBS)
POST /api/erumi-roadmap/chat Project Member Chat tự do và nhận phản hồi kèm bản thảo Proposal
POST /api/erumi-roadmap/approve Project Owner / PM Phê duyệt Diff Proposal & ghi danh sách Task vào Database
POST /api/erumi-roadmap/rollback Project Owner / PM Hoàn tác 1-Click Snapshot đã duyệt trong vòng 72 giờ
GET /api/erumi-roadmap/simulation-sandbox Project Member Lấy kết quả mô phỏng kịch bản What-If mà không ghi DB

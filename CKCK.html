🔒 DB Unique Filtered Index

Bảo vệ chống Race Condition ở DB: CREATE UNIQUE INDEX ... WHERE EndDate IS NULL. Đảm bảo ở cấp Database tuyệt đối không bao giờ tồn tại 2 record active cùng lúc cho 1 member.

⚠️ Đủ Cả 2 Warning Modals

Phase 2 triển khai đủ 2 UI Modal: Modal (a) Overlap thời gian gán role mới & Modal (b) System Limit vs Project Role Preference conflict.

📜 Chốt 2 Policy Quan Trọng

(1) Task cũ đã assign cho User thì User giữ nguyên quyền Edit tới khi đóng task; (2) Role History chỉ chính thành viên đó + Owner/PM/Admin được quyền xem.

#1. DB Unique Filtered Index Chống Race Condition

🔒 EF Core Entity Configuration & Migration:
// EF Core DbContext Configuration
builder.Entity<ProjectMemberRoleHistory>()
    .HasIndex(h => h.ProjectMemberId)
    .IsUnique()
    .HasFilter("\"EndDate\" IS NULL");

SQL tự động sinh ra:
CREATE UNIQUE INDEX IX_ProjectMemberRoleHistory_Active ON "ProjectMemberRoleHistory" ("ProjectMemberId") WHERE "EndDate" IS NULL;

🛡️ Lợi Ích Của DB Index Filtered:

Dù cho Admin thao tác click đúp chuột cực nhanh hoặc 2 request API bắn đồng thời (Race condition), Database sẽ tự động từ chối transaction thứ hai. Đảm bảo ở tầng dữ liệu vĩnh viễn chỉ có duy nhất **1 Active Role Record**.
